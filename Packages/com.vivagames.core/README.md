# Viva Core

Base package of the Viva Games Unity tools. It provides:

- **Viva > Package Installer**: installs, updates and removes the other Viva modules from GitHub.
- Shared editor utilities used by the modules (`ScriptingDefines`, `VivaPackageUtility`).

Install it once from the Package Manager with the git URL and use the installer window for everything else.
Full documentation in the [repository README](https://github.com/Viva-Games/Viva-Analytics-Tool#readme).
